## Принятые решения

- **Стек:** чистый HTML + CSS + немного vanilla JS, без сборщиков и фреймворков. Файлы отдаются GitHub Pages как есть.
- **Языки:** русский и узбекский (латиница). Русский — главный (утверждено).
  - `/index.html` — RU, `/uz/index.html` — UZ
  - общие `/assets/css/`, `/assets/js/`, `/assets/img/`
  - переключатель языка в шапке, `hreflang`, `lang` у `<html>`
  - узбекский текст Аббос вычитывает сам перед публикацией
- **Дизайн** создаётся прямо в сессии: сначала согласовать визуальное направление (референсы от Аббоса → палитра и шрифты), затем верстать по одной секции, показывать скриншоты десктоп + телефон (Playwright), править.
- **Mobile-first**: большинство клиентов придёт с телефона из Instagram/Telegram.

## Правила по содержанию (важно)

- **Не выглядеть как Meta**: без логотипов Meta/Facebook/Instagram, без фирменных цветов и шрифтов Meta, без слов «официальный», «партнёр Meta», «представитель». В футере — пометка: «Независимый специалист. Не связан с Meta Platforms, Inc.»
- **Не обещать гарантированную разблокировку** — «помогу правильно оформить апелляцию и пройти процесс».
- Опыт — как экспертиза («знаю, как устроены правила и ревью»), никаких намёков на «связи внутри Meta».
- Без выдуманных статистик, отзывов и логотипов клиентов.
- Иконки — inline SVG, без эмодзи.
